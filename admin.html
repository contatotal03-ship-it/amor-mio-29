☁️ Conexión a la Nube (Supabase + GitHub Pages)

Para que tú autorices capítulos desde tu celular y se desbloqueen al instante en el celular de ella (con fotos y videos en la nube, cero spoilers):
1) Crea un proyecto gratis en supabase.com.
2) En SQL Editor pega el contenido del archivo supabase_schema.sql.
3) En Authentication → Users crea TU usuario Admin (email y contraseña).
4) Pega abajo tu Project URL y Anon Key, y luego descarga tu config.js para subirlo a GitHub.
